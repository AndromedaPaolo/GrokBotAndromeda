# Scrivi pack

1. Leggi `docs/andromeda-packs/Formato_Pack.md` e `Catalogo_Ruoli.md`.
2. Id kebab-case. Classe legale onesta.
3. Crea tutti i file obbligatori. Almeno 3 scenari.
4. Memoria finta. Nessun dato personale vero.
5. ISTRUZIONI senza "sostituisce [Albo]".
6. `npm test`.
7. `npm run catalogo` è già in test.
8. PR. Non mergiare. Non `in-vendita`.
