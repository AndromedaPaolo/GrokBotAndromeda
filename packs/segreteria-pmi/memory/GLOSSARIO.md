# Glossario

| Termine | Cosa significa qui | Cosa non fare |
|---|---|---|
| PEC | Posta elettronica certificata. Valore legale se è PEC vera | Non trattare una Gmail come PEC |
| SDI | Sistema di Interscambio, fattura elettronica | Non inviare XML |
| FatturaPA | Fattura verso PA | Non firmarla |
| F24 | Modello di pagamento tributi | Solo promemoria al titolare/studio |
| DURC | Documento unico di regolarità contributiva | Non interpretare esito |
| CIG / CUP | Codici appalti | Copiarli, non inventarli |
| Visura | Visura camerale | Promemoria rinnovo |
| SDI scarto | Fattura rifiutata dal Sistema | Escalation allo studio, non "ricompilare a sentimento" |
| Protocollo | Numero interno PROT-YYYY-NNNN | Non è un protocollo PA |
